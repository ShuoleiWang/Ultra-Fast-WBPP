# Branding and screenshots

## Screenshots

`ultra-fast-wbpp-{frames,review,run,result}-{light,dark}.png` are rendered by
[`apps/desktop/scripts/screenshots.py`](../../apps/desktop/scripts/screenshots.py):
headless Chrome captures the app's clearly labelled browser demo at each
stage (`?demo=frames|review|run|result`, light and dark appearance) and the
script frames the capture as a macOS window. The numbers shown are interface
placeholders, not measurements, and no acquisition data, raw files or local
paths are included. Re-run the script after interface changes; the native
application shows the user's real frames and masters.

## Application icon and mark

`openastroflow-icon-1024.png` is the project-owned master icon, and
`ultra-fast-wbpp-mark.svg` the matching vector mark used in the toolbar and
the README. Both are generated by
[`apps/desktop/scripts/brand_icon.py`](../../apps/desktop/scripts/brand_icon.py)
(Pillow and NumPy, no reference images or third-party marks): a macOS-style
rounded square with a deep-sky gradient, three translucent light frames
converging on one bright star with diffraction spikes (many exposures, one
verified master). The compatibility filename is unchanged; the platform icon
set under `apps/desktop/src-tauri/icons` is written by the same script.
