## Application icon

`openastroflow-icon-1024.png` is the project-owned master icon, generated September 1, 2026 without reference images or third-party marks. The compatibility filename remains unchanged. Derived platform icons are under `apps/desktop/src-tauri/icons`.

The design depicts translucent star-field frames converging into a star and celestial-coordinate grid, using navy, indigo, cyan, and violet. It contains no third-party logos, application artwork, or camera/telescope marks.
